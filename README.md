4. Give the archive a name.

## ⚠️ IPA Installation

An `.ipa` file is an iOS application package. Simply placing an IPA on GitHub Pages does **not** guarantee that an iPad can install it.

For an actual installation, the IPA generally needs to be appropriately signed/provisioned for the device and compatible with the installed iOS version. Very old iOS releases such as those used by the original iPad have additional compatibility and installation limitations.

This archive page therefore treats **Install App** as a link to the corresponding IPA package rather than guaranteeing installation.

---

## 📦 IPA Package Structure

A typical IPA has a ZIP-based structure similar to:

```text
Animal Sounds 2.0.ipa
└── Payload/
    └── Animal Sounds.app/
        ├── Info.plist
        ├── Animal Sounds
        ├── Icon.png
        └── ...
```

The same structure applies to the other applications, with the appropriate `.app` bundle name.
